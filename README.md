Senior Staff Scientist at EMBL Heidelberg. Applied mathematician (PhD, Oxford) working across scientific software, data pipelines and pharmacometric modelling.

## What I do

**Scientific software engineering**
- Production Python/R packages with tests, CI/CD, containers and versioned releases
- Maphelios on PyPI, deployed with GitLab CI/CD and Kubernetes
- Python 11 yrs, R 6 yrs, C++ 5 yrs

**Data engineering and AI**
- 20+ Snakemake/Nextflow pipelines on SLURM

- LLM-based agentic extraction of structured knowledge from literature
